# **App Name**: Yesterday's Headlines

## Core Features:

- Live News Feed: A vertical list of editorial cards displaying article images, bold headlines, and metadata snippets.
- Topic Navigator: Horizontal scroll bar to filter the news feed by 'All', 'Livelihood', 'Technology', and 'Society' categories.
- Temporal Top Bar: An interactive header showing the app brand and a dynamically generated date for the reader's current location.
- Headline Generator Tool: A generative AI tool that analyzes article bodies to create catchy, bold titles for each news card in the feed.
- Local JSON Integration: Data management system for fetching and mapping structured headline data from a local JSON endpoint.
- Geotag Metadata: Automated display of time and location metadata on cards based on the article's specific source info.

## Style Guidelines:

- Primary color: Vibrant Crimson (#F22626) for the splash screen and urgent brand accents.
- Background: Sophisticated Deep Obsidian (#171212) to provide a premium dark-mode aesthetic for high readability.
- Accent: Sunset Orange (#FFB333) for tags and call-to-action highlights, offering an analogous contrast to the primary red.
- Headline font: 'Playfair' serif for an elegant, high-end editorial feel; Body/Tag font: 'PT Sans' sans-serif for warmth and clarity.
- Thin-stroke, minimal linear icons for navigation to maintain a professional newsroom appearance.
- A clean card-based layout featuring a specific 'Image-Left, Text-Right' structure to prioritize fast scanning.
- Smooth fade-in transitions for headlines and horizontal slide effects for the category filter selection.
